CreateAI Pro — Starter Website Template
=======================================

ही ZIP Cloudflare Pages च्या Direct Upload साठी तयार केलेली static website आहे.

फोल्डरमध्ये:
- index.html
- assets/style.css
- assets/app.js

Cloudflare Pages वर अपलोड करण्याची पद्धत (मोबाईल):
1. ZIP डाउनलोड करून फोनमध्ये Extract/Unzip करा.
2. Cloudflare Dashboard > Workers & Pages > Create application > Pages > Upload assets (किंवा Drag and drop) निवडा.
3. ZIP ऐवजी Extract केलेला फोल्डर किंवा त्यातील index.html आणि assets फोल्डर एकत्र अपलोड करा. जर ZIP स्वीकारत असेल तर ZIP अपलोड करा.
4. Project name: createaipro ठेवा आणि Deploy करा.
5. Deploy झाल्यावर मिळालेला pages.dev URL उघडून तपासा.

महत्त्वाच्या मर्यादा:
- ही सध्या फक्त frontend/demo template आहे.
- Generate बटणे खरे AI फोटो किंवा व्हिडिओ तयार करत नाहीत.
- Login, user database, credit tracking, admin authentication, payment gateway आणि auto subscription activation अजून जोडलेले नाहीत.
- Razorpay/इतर payment gateway जोडण्यापूर्वी backend, webhook verification, privacy policy, terms आणि refund policy तयार करा.
- API keys कधीही HTML/JavaScript मध्ये ठेवू नका. त्या server-side secrets म्हणूनच ठेवा.
